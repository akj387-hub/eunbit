# eunbit 저장소 조사 결과 (2026-11-07)

## 결론
- 이 저장소에는 일당직표·연차달력의 **데이터와 규칙이 없다**. 홈 화면 바로가기용 안내 페이지만 있다.
- 실제 기능은 Google Apps Script 웹앱(script.google.com)에 있고, 저장소는 그쪽으로 넘겨주기만 한다.
- 아침돌봄수당 관련 파일은 저장소에 없다.

## 구조
| 경로 | 내용 |
|---|---|
| index.html | "은빛도담어린이집" 바로가기 목록 (일당직표, 연차달력) |
| duty/ | 일당직표 바로가기 (index.html, manifest, 아이콘). 초록 #3f6b3a |
| leave/ | 연차달력 바로가기. 주황 #d0723f |

- duty/index.html, leave/index.html은 제목·색·APP 주소만 다르고 동일한 구조.
- `?go=1`이면 APP 주소(Apps Script 웹앱)로 즉시 이동. 홈 화면에 추가하면 이 주소로 저장됨.
- 커밋: 2026-10-18 업로드 3건 (index.html 생성, duty, leave).

## 자동화 계획(5·6번)에 주는 의미
- 일당직표·연차달력의 원본은 **Apps Script 웹앱 + 그 뒤의 구글 시트(추정)**. 시트 여부는 코드를 못 봐서 미확인.
- 대조 자동화에 필요한 것: 웹앱 소스(Apps Script 프로젝트) 또는 연결된 시트, 데이터 구조, 연장반 대체 규칙.
- 웹앱 주소를 AI가 읽을 수 있는지(로그인/공개 여부)도 미확인. 직원 개인정보(연차)가 담겼을 수 있어 읽기 시도는 하지 않음.
- 과거 대화 검색에서 못 찾은 이유: 작업이 이 GitHub 저장소·Apps Script 쪽에서 이뤄졌을 가능성이 큼. 단 이 저장소 기록은 업로드 커밋뿐이라 작업 대화 내용은 알 수 없음.
